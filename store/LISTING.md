## Store listing tab

**Name** (from the manifest): `ArtikelFinder`

**Summary** (from the manifest `description`, 109 of max 132 characters):
> Shows der, die or das for a selected German noun, including inflected forms, with the source of every answer.

**Description** (plain text, paste as is):

```
Learning German? Select any noun on any web page and ArtikelFinder tells you its article: der, die or das.

It understands inflected forms, not just dictionary entries. Select "Tischen" and it answers: der Tisch, dative plural. You also get the plural and a full declension table.

HOW TO USE
Select a word, then right-click and choose "Artikel für …", or press Alt+Shift+A. (If the shortcut does nothing, set it under chrome://extensions/shortcuts.)

EVERY READING, NOT A GUESS
Some forms belong to more than one word. "Leitern" can be die Leiter (ladder) or der Leiter (leader); "See" can be der See (lake) or die See (sea). ArtikelFinder shows every possible reading instead of silently picking one.

HONEST ABOUT HOW SURE IT IS
Every answer carries a label: "2 sources agree", "1 source", or "Sources disagree", in which case you also see what the other source says. Unknown words get a clear "not in the dictionary", never a made-up answer.

PRIVATE BY DESIGN
- The whole dictionary (about 196,000 nouns) ships inside the extension and works offline.
- No servers, no accounts, no tracking, no data collection.
- It reads a page only when you ask it to look up a word. Chrome shows no "read and change all your data on all websites" warning, because it does not need that permission.

OPEN SOURCE
Code: MIT license. Dictionary data: CC BY-SA 3.0, built from UniMorph (derived from Wiktionary) and Wikidata. Source code and details:
https://github.com/souissinebilAI/ArtikelFinder

LIMITATIONS
German nouns only, no sentence context (both readings of "Leitern" are shown, not the one that fits the sentence), and compound words that are not in the dictionary are not split yet.
```

## Privacy tab

**Single purpose description:**
```
Show the grammatical article (der, die or das), lemma, case and number of a German noun that the user selects on a web page, using a dictionary bundled with the extension.
```

**Permission justifications:**

`contextMenus`
```
Adds one entry, "Artikel für …", to the right-click menu when text is selected. Choosing it starts a lookup of the selected word.
```

`activeTab`
```
Gives temporary access to the current tab only after the user chooses the menu entry or presses the extension's keyboard shortcut, so the extension can read the selected word and show the result next to it. The extension requests no host permissions and has no access to pages at any other time.
```

`scripting`
```
Used after the user asks for a lookup: injects the extension's own bundled script that draws the result bubble in the current tab, and, for the keyboard shortcut, reads the currently selected text. No remote code is injected.
```

**Remote code:** No, I am not using remote code. (All JavaScript is in the package; the
extension makes no network requests.)

**Data usage:** tick **none** of the data types (the extension collects nothing), then tick
all three certifications:
- I do not sell or transfer user data to third parties, outside of the approved use cases
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose
- I do not use or transfer user data to determine creditworthiness or for lending purposes
